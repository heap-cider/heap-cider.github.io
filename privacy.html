Loomoa 개인정보처리방침

시행일: 2026년 11월 23일

1. 개요

Loomoa는 사용자의 PC에서 실행되는 개인용 데스크톱 앱입니다. Loomoa 개발자는 사용자 데이터를 수집하거나 보관하는 서버를 운영하지 않으며, 사용자 데이터를 개발자에게 보내지 않습니다.

2. Google 사용자 데이터에 접근하는 범위

  • 사용자가 Google 계정 연결을 직접 승인한 경우에만 접근합니다.
  • Gmail 메일과 라벨을 읽기 전용으로 조회합니다. 메일을 보내거나 지우거나 고치지 않습니다.
  • 사용자가 요청한 작업(예: 특정 메일 찾기, 받은 메일 요약)에만 사용합니다.

3. 보관

  • Google 로그인 토큰은 사용자 PC의 운영체제 자격증명 저장소에만 저장하며, 다른 기기로 동기화하지 않습니다.
  • Loomoa는 메일을 따로 복사해 저장하지 않습니다. 다만 사용자가 요청한 작업의 결과는 사용자 PC에 있는 Loomoa 대화 기록에 남을 수 있습니다.

4. 제3자 제공

  • Google 사용자 데이터를 판매하거나 광고에 쓰지 않습니다.
  • 사용자가 요청한 작업을 처리하기 위해, 메일 내용의 일부가 사용자가 직접 설치하고 설정한 AI 실행 도구(예: Claude Code, Codex)에 전달될 수 있습니다. 이 경우 해당 도구 제공자의 정책이 적용됩니다.

5. Google API 서비스 사용자 데이터 정책 준수

Loomoa가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 연결 해제와 삭제

Loomoa에서 해당 커넥터를 삭제하거나 Google 계정의 서드 파티 연결 화면에서 Loomoa의 접근을 해제할 수 있습니다. 해제하면 사용자 PC에 저장된 토큰은 더 이상 쓰이지 않습니다.
